# Financial Analytics Dashboard

## Project Overview
This project analyzes financial sales data using Python, Excel, and Power BI to identify sales, profit, product, country, segment, and discount performance.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Excel
- Power BI
- GitHub

## Key Analysis
- Country-wise Gross Sales
- Product-wise Profit
- Month-wise Sales Trend
- Segment-wise Sales and Profit
- Discount Band-wise Profit
- Country-wise Profit
- Key Performance Indicators (KPIs)

## Dashboard Features
- Total Gross Sales
- Total Profit
- Total Units Sold
- Total Sales
- Interactive Country Slicer
- Interactive Year Slicer
- Multiple financial performance charts

## Key Insights
- Identified countries contributing the highest gross sales.
- Compared product-wise profitability.
- Analyzed monthly sales trends.
- Compared sales and profit across business segments.
- Evaluated the impact of discounts on profit.

## Business Recommendations
- Focus on high-performing countries and products.
- Monitor discount strategies to protect profitability.
- Identify low-performing segments for improvement.
- Use monthly trends for better sales planning.

## Conclusion
The project provides an interactive financial analytics dashboard that helps understand sales and profitability performance and supports data-driven business decisions.
